# 模型来源 / Model sources

- 双停机坪直升机场、独立停机坪、Mil Mi-26TC：项目提供的Transport Fever 3模型导出资源。
- 来源清单：assets/helicopter/heliport/native_manifest.json、assets/helicopter/helipad/native_manifest.json、assets/helicopter/mil_mi26tc/native_manifest.json。
- Cities: Skylines II中的资源转换、线路管理、起降和市民运输：本模组实现。
- 本条目是模型移植与独立运输模组，未声称是原游戏开发商的官方作品。

## English

- Twin-pad heliport, independent helipad and Mil Mi-26TC: model resources exported from Transport Fever 3 and supplied to this project.
- Source manifests in the project: assets/helicopter/heliport/native_manifest.json, assets/helicopter/helipad/native_manifest.json and assets/helicopter/mil_mi26tc/native_manifest.json.
- Native conversion, passenger transport, line management and flight behavior in Cities: Skylines II: implemented by this mod.
- This is a model port and independent transport mod; it does not claim to be an official product of the original game's developer.
